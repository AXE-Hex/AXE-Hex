## About Me

I am focused on **cybersecurity, Digital Forensics & Incident Response (DFIR), AI-assisted security automation, Linux, networking, and secure software development**.

My work combines security engineering with practical software systems—from academic platforms and e-commerce applications to local AI tooling, network-security workflows, and DFIR labs.

- **Security:** DFIR, incident response, network analysis, security automation
- **AI:** local LLMs, AI-assisted workflows, security-focused automation
- **Engineering:** Flutter, Next.js, React, FastAPI, Supabase, PostgreSQL
- **Systems:** Fedora Linux, Kali Linux, Windows, virtualization
- **Current direction:** AI-assisted cybersecurity and DFIR systems
